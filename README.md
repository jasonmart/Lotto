### 🎲 Vintage Lotto Number Generator

A lightweight, purely frontend lottery number generator built using vanilla web technologies. 

This repository is maintained publicly to preserve my historical coding timeline, demonstrating a foundational milestone in my software development journey. 

### 📅 Timeline Context

* **Original Development:** 2017 (9 years ago)
* **Objective:** Explore core JavaScript logic, DOM manipulation, and basic CSS styling without external frameworks or dependencies.
* **Current Status:** Archive / Legacy Project. This repository is kept in its original state to showcase my early coding style, problem-solving evolution, and long-term commitment to the craft.

### 🛠️ Tech Stack

* **HTML5:** Semantic structure for the generator layout.

### 📝 Reflections & Growth

Looking back at this code after 9 years, it serves as a great reminder of how far I have come. If I were to rebuild this project today using modern standards, I would: 

* Implement robust state management and modular ES modules.
* Use a modern build tool like Vite and a framework like React or Vue for scalability.
* Apply responsive design principles using modern layout engines like CSS Grid or Flexbox.
* Write comprehensive unit tests for the randomization logic.
